## DF-005 — UI 자동 테스트 [구현 중 / CI 실행 검증 대기]

작업 명세: [DF-005 TASK](tasks/DF-005.md)

## DF-001 — 일정 검색 [PR #2 구현 완료 / UI 검증 확장 대기]
완료 조건: 제목/메모를 대소문자 구분 없이 검색한다. 검색은 선택 날짜 내에 적용한다. 빈 검색어는 전체 목록을 표시한다. 검색 결과가 없는 상태를 표시한다. 검색 로직 테스트와 iOS 빌드가 통과한다.

## DF-002 — 로컬 알림 [PR #3 구현 완료 / UI·실기기 QA 대기]
완료 조건: 사용자 요청으로 알림 권한을 받는다. 권한 거부 상태를 설명한다. 수정/삭제 시 기존 알림을 갱신/취소한다. 과거 일정은 예약하지 않는다. 실제 기기 알림 도착 여부를 별도로 기록한다.

## DF-003 — 종일 일정 [대기]
완료 조건: 날짜만 선택할 수 있다. 기존 JSON을 계속 읽을 수 있다. 날짜/시간대 경계 테스트가 통과한다.

## DF-004 — 비동기 저장소 [대기]
완료 조건: 저장 I/O가 UI를 차단하지 않는다. 빠른 연속 수정에서도 마지막 데이터가 보존된다. 실패/재시도 상태와 순서 보장 테스트가 있다.
