# DF-001 — 선택 날짜의 일정 검색

상태: 구현 완료 / 화면 QA 대기 — docs/VALIDATION.md 참조

## 목적

사용자가 선택한 날짜의 일정 중 제목 또는 메모에 검색어가 포함된 일정을 빠르게 찾는다.

## 사용자 동작

1. DayFlow 메인 화면에서 날짜를 선택한다.
2. 검색창에 검색어를 입력하면 해당 날짜에 겹치는 일정 중 일치하는 일정만 즉시 표시한다.
3. 검색어를 지우면 선택 날짜의 모든 일정을 표시한다.
4. 검색 중 날짜를 변경하면 검색어를 유지하고 새 날짜의 결과를 표시한다.
5. 검색 결과에서도 일정 편집, 완료 표시, 삭제 기능을 사용할 수 있다.

## 검색 규칙

- 제목 또는 메모 중 하나에 검색어가 포함되면 일치한다(OR, 부분 문자열 검색).
- 영문 대소문자를 구분하지 않는다. 한국어는 입력한 문자열로 검색한다.
- 검색어 앞뒤의 공백과 줄바꿈을 제거한다. 내부 공백은 유지한다.
- 빈 문자열이나 공백만 입력하면 검색 필터를 적용하지 않는다.
- 검색 범위는 선택한 날짜에 겹치는 일정이며 기존 `overlaps(day:calendar:)` 규칙을 사용한다.
- 완료 여부와 관계없이 검색하고, 결과는 기존과 같이 시작 시간 오름차순으로 표시한다.
- 여러 단어를 분리하는 검색, 초성 검색, 오타 보정은 이번 범위에 포함하지 않는다.

예시: 제목이 `Team Meeting`, 메모가 `회의실 B`인 오늘 일정은 `meeting` 또는 `회의실`로 찾을 수 있다. 동일한 내용의 내일 일정은 오늘 검색 결과에 나타나지 않는다.

## 화면 요구사항

- SwiftUI `.searchable`로 메인 목록에 검색창을 제공한다. 안내 문구는 `제목 또는 메모 검색`으로 한다.
- 목록의 일정 개수는 현재 필터링된 결과 수를 표시한다.
- 검색어가 없고 일정도 없으면 기존 `등록된 일정이 없어요` 상태를 표시한다.
- 검색어가 있고 일치 항목이 없으면 `검색 결과가 없어요`와 `검색어나 날짜를 바꿔보세요.`를 표시한다.
- 편집 후 검색 조건에서 벗어난 일정은 결과에서 사라지고 개수도 갱신된다.
- 검색어는 화면 상태로만 유지하며 앱 재실행 시 복원할 필요는 없다.

## 구현 범위와 제약

- App/ScheduleListView.swift: 검색 입력 상태, 결과 목록, 개수, 빈 상태를 연결한다.
- Core/: 날짜와 검색어를 함께 처리하는 순수 검색 로직을 작성한다. 테스트에서 Calendar를 주입할 수 있게 한다.
- Tests/: 아래 검색 동작을 검증한다.
- docs/QA.md: 검색 기능의 수동 확인 항목을 추가한다.
- iOS 17 이상, SwiftUI와 기존 Observation 구조를 유지한다.
- 외부 패키지, 네트워크 요청, 새로운 저장 형식을 추가하지 않는다.
- 기존 JSON 파일, 일정의 ID 및 저장·오류 처리 동작을 유지한다.

## 완료 조건

- [ ] 제목과 메모 각각의 부분 문자열로 검색할 수 있다.
- [ ] 영문 대소문자를 구분하지 않는다.
- [ ] 검색어 앞뒤 공백은 제거하며 공백만 있는 검색어는 전체 목록을 반환한다.
- [ ] 다른 날짜의 일정은 제외하고 자정을 넘기는 일정은 기존 날짜 겹침 규칙을 따른다.
- [ ] 검색어를 지우면 선택 날짜 전체 목록을 복원한다.
- [ ] 검색어를 유지한 채 날짜를 변경할 수 있다.
- [ ] 검색 결과의 개수, 시작 시간 정렬, 빈 상태가 정확하다.
- [ ] 검색 결과에서도 편집·완료·삭제가 동작하고 결과가 즉시 갱신된다.
- [ ] 핵심 검색 테스트와 기존 테스트가 통과한다.
- [ ] iOS Simulator 대상 빌드가 성공한다.
- [ ] 수동 화면 확인 결과와 실행하지 못한 검증을 기록한다.

## 검증 계획

자동 테스트:

- 제목 일치, 메모만 일치, 양쪽 모두 불일치.
- 영문 대소문자 혼합과 한국어 부분 문자열.
- 빈 검색어, 공백만 있는 검색어, 앞뒤 공백이 있는 검색어.
- 다른 날짜 제외, 자정 경계와 다음 날짜 시작 경계.
- 완료 일정 포함과 시작 시간 정렬.

실행 명령:

```sh
./scripts/verify.sh
```

수동 확인:

1. 선택 날짜에 제목이 `Team Meeting`, 메모가 `회의실 B`인 일정과 관련 없는 일정 두 개를 만든다.
2. 다른 날짜에도 같은 제목의 일정을 만든다.
3. `meeting`, `회의실`, 공백만 있는 검색어를 각각 입력하고 결과와 개수를 확인한다.
4. 존재하지 않는 검색어로 빈 결과 문구를 확인한다.
5. 검색어를 유지하고 날짜를 변경한 뒤 다시 검색어를 지운다.
6. 검색 결과의 일정을 편집·완료·삭제하며 목록 갱신을 확인한다.
7. 기본 모드와 --demo에서 확인하고, 저장 실패 모드에서는 기존 오류 처리가 유지되는지 확인한다.
