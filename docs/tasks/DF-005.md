# DF-005 — UI 반복 테스트 우선 기반

상태: 구현 완료 / CI 실제 실행 검증 중

## 목적과 우선순위

화면을 매번 사람이 조작하지 않아도 기본 동작을 반복 검증할 수 있게 합니다. DF-005를 다음 최우선 작업으로 옮기며 이후 순서는 DF-001 UI 검증 → DF-002 UI 검증 → DF-004 → DF-003입니다. 기존 TASK 번호는 유지합니다.

## 범위

- main 기준 독립 DayFlowUITests 타깃 및 공용 스킴 TestAction.
- --demo로 실제 앱을 실행하는 XCUITest.
- 추가·수정·완료·완료 취소·삭제 한 흐름.
- 빈 제목·공백 제목 저장 차단과 편집 취소.
- 데모 재실행 초기화.
- 화면 동작을 바꾸지 않는 접근성 식별자와 완료 상태 값.
- 시뮬레이터 자동 선택, 테스트 실행 스크립트, CI 실행 및 xcresult/스크린샷 보관.
- 검색·알림 기능 자체는 기존 TASK별 PR에서 이 기반을 적용한 후 추가 검증.

## 완료 조건

- [ ] UI 테스트 타깃과 앱이 build-for-testing에 성공한다.
- [ ] 실제 iOS Simulator에서 UI 테스트 3개가 통과한다.
- [ ] 기존 Core 테스트와 iOS 빌드가 통과한다.
- [ ] CI에서 UI 테스트가 실제 실행되고 결과 번들을 보관한다.
- [ ] 우선순위와 이후 화면 기능의 테스트 선행 규칙을 문서화한다.

## 검증

./scripts/verify.sh와 ./scripts/ui-test.sh를 실행합니다. 테스트 빌드와 실제 실행을 구분하고, 로컬 서비스 문제로 실행이 막히면 CI 결과로 확인합니다. 실제 화면을 조작하되 저장소는 메모리 데모를 사용하므로 실제 데이터에 영향을 주지 않습니다.

시각적 품질과 실기기 알림 수신은 완료 범위 밖이며 해당 TASK의 수동 QA로 유지합니다.
