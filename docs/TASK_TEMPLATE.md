# AI 작업 요청 템플릿

## 작업 ID와 목적
예: DF-001, 일정이 많을 때 빠르게 찾기

## 사용자 동작
어느 화면에서 어떤 조작을 하면 어떤 결과가 나오는지 작성

## 완료 조건
관찰 가능한 동작, 오류/빈 상태, 필요한 테스트를 작성

## 제약
지원 OS, 기존 데이터 호환성, 수정하지 않을 범위를 작성

## 수행 요청
AGENTS.md를 읽고 관련 코드를 조사한 뒤 구현한다. scripts/verify.sh와 필요한 화면 검증을 수행한다. 변경 내용, 검증 결과, 미검증 항목을 보고하고 BACKLOG 상태를 갱신한다.

## PR 완료 절차

실제 테스트와 iOS 빌드가 통과하면 커밋·push 후 PR 작성까지 진행한다. 기존 작업 PR이 있으면 갱신한다. 화면/실기기 QA가 남으면 초안으로 작성하고 미검증 항목을 명시한다. 실패를 성공으로 표현하지 않으며, 병합과 배포는 별도 지시 없이 수행하지 않는다.

TASK마다 독립 브랜치와 PR 하나를 작성한다. 여러 TASK를 동시에 개발해도 PR을 합치지 않는다. PR 제목에 해당 TASK ID 하나를 표시한다.
