# 수동 화면 확인

- 기본 모드: 일정 추가 후 앱 종료/재실행 시 유지되는지 확인
- 날짜 변경: 다른 날의 일정이 섞이지 않는지 확인
- 자정 경계: 전날 23시~오늘 01시 일정이 양쪽 날짜에 나타나는지 확인
- 빈 제목/종료가 시작보다 빠른 입력: 저장 버튼 비활성 확인
- 수정/취소: 저장한 변경만 반영되는지 확인
- 완료 표시: 완료 취소와 재실행 후 유지 확인
- 삭제: 취소 시 유지, 확인 시 삭제 확인
- --demo: 예시 표시, 재실행 시 초기화, 실제 데이터 유지 확인
- --demo --error-demo: 저장 실패 후 기존 목록 유지 확인
- 큰 글자와 VoiceOver: 입력, 완료, 편집, 삭제 접근성 확인

빌드 성공만으로 이 항목들을 통과로 처리하지 않습니다.


## DF-005 자동 UI 회귀 범위

- 추가 → 수정 → 완료/완료 취소 → 삭제 확인
- 빈 제목/공백 제목 저장 차단, 취소 후 미생성 확인
- --demo 재실행 시 초기화 확인

실행: ./scripts/ui-test.sh. 실제 실행 결과는 docs/VALIDATION.md에 기록합니다. 자동화 범위 밖의 화면 배치·큰 글자·VoiceOver·실기기 알림은 기존 수동 확인 항목을 유지합니다.

## DF-001 검색 회귀 확인

- 제목/메모 검색, 영문 대소문자 혼합과 한국어 검색 결과 확인
- 공백만 입력하거나 검색어를 지우면 선택 날짜 전체 목록 복원 확인
- 날짜 변경 시 검색어 유지, 다른 날짜 일정 제외 및 자정 경계 확인
- 검색 결과 없음 문구와 결과 개수 확인
- 검색 결과의 편집·완료·삭제 후 목록 갱신 확인

## DF-002 로컬 알림 회귀 확인

- 앱 시작 시 권한 팝업 없음, 편집 토글로 최초 요청 확인
- 허용/거부/제한된 허용 상태, 설정에서 변경 후 앱 복귀 확인
- 미래 일정 저장 후 예약, 편집 취소 시 미예약 확인
- 제목/시간 수정과 삭제·완료·알림 끄기 후 이전 예약 정리 확인
- 저장 실패 시 기존 예약 유지, 예약 실패 시 저장 성공과 구분된 안내 및 재시도 확인
- 재실행과 빠른 연속 변경 후 저장 데이터와 예약 일치 확인
- 32개 초과 시 대기 안내와 가까운 일정 우선 예약 확인
- --demo/--error-demo에서 실제 권한 요청·예약·취소 없음 확인
- 실기기 전면/백그라운드에서 실제 도착을 각각 확인하고 기기/OS/알림 설정 기록
